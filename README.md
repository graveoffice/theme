Grave Office
Theme

Overview:
TypeScript-first light and dark themes for VS Code / Cursor and Zed.

Usage:
VS Code / Cursor
  1. Install `Grave Theme` from your extension marketplace.
  2. Open Command Palette -> `Preferences: Color Theme`.
  3. Select `Grave Light` or `Grave Dark`.

npm / Shiki
  npm install @grave/theme

  import graveDark from "@grave/theme/grave-dark";
  import graveLight from "@grave/theme/grave-light";

Zed
  Install `Grave` from the Zed extension registry.
